## 📌 About the Project

This project was developed as part of my **Codec Technologies Internship**.

Market Basket Analysis identifies products that are frequently purchased together using the **Apriori Algorithm**.

The project includes an interactive Streamlit dashboard for exploring association rules.

## ✨ Features

- 🧹 Data cleaning and preprocessing
- 🧠 Apriori algorithm
- 🔗 Association rule generation
- 📊 Support, Confidence & Lift analysis
- 📈 Interactive Streamlit dashboard
- 📥 Export association rules as CSV

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Programming |
| Pandas | Data Processing |
| MLxtend | Apriori Algorithm |
| Matplotlib | Visualization |

## 🚀 How to Run

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/sharadjain766-ai/Market-Basket-Analysis.git
```

```bash
cd Market-Basket-Analysis
```

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 3️⃣ Run the Streamlit App

```bash
python -m streamlit run app.py
```

The dashboard will open in your browser.

### 4️⃣ Run the Jupyter Notebook (Optional)

```bash
jupyter notebook
```

Open:

```text
Market_Basket_Analysis.ipynb
```

## 📊 Results

## 💼 Applications

## 🚧 Limitations

- Analysis is limited to the top 150 products.
- The current version focuses on product pairs.
- Results depend on selected support and confidence values.
